📄

2. Targeted Page Component

Isolated component handles only its local state. Triggers API strictly on mount hook or user interaction (Zero duplicate cascading calls).

▼
🛡️

3. Interceptor Service (backend.js)

requestApi() attaches Authorization: Bearer <token>, inspects 1-hour session validity, and catches 401s.

▼
⚡

4. NestJS & PostgreSQL (ACID Guard)

Controller validates DTO ➔ Service performs atomic transaction ➔ Returns serialized JSON back to frontend view.

Customer Storefront Route Protection (`RequireCustomer`)

Accessible only by authenticated customers or public guests. If an active administrator attempts to visit storefront routes, they are automatically redirected to /admin.
