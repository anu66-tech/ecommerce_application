End-to-End Pipeline Architectural journey of every HTTP request, from React interaction to PostgreSQL ACID commit.
1

User Action / Navigation

Customer clicks an item or navigates via React Router. The target modular page mounts.

React Router v6 Custom Hook
2

Role Route Guard

RequireCustomer or RequireAdmin verifies the JWT role payload. Exclusivity enforced.

RequireCustomer RequireAdmin
3

Native Fetch Interceptor

requestApi() in backend.js injects Authorization: Bearer <token> and checks 1-hr expiry.

Bearer Token 401 Auto-Logout
4

NestJS Controller & DTO

Incoming request validated via class-validator DTOs. Invalid parameters immediately returned with 400 Bad Request.

ValidationPipe JWT Strategy
5

Service Business Logic

Pure TypeScript business logic validates inventory stock levels, password hashes (bcrypt), and order calculations.

Prisma ORM Bcrypt Hash
6

PostgreSQL ACID Transaction

Atomic transaction committed to PostgreSQL database (port 5432). Synchronous response delivered back to frontend.

ACID Compliant PostgreSQL
