3. Lifecycle & Query Execution Flow

sequenceDiagram
    autonumber
    actor Client as Frontend / HTTP Client
    participant Ctrl as NestJS Controllers
    participant Svc as StoreService / ProductsService
    participant PS as PrismaService
    participant PG as PostgreSQL

    Note over PS,PG: Boot Phase (onModuleInit)
    PS->>PG: $connect() via PrismaPg Adapter
    PG-->>PS: Connection established

    Note over Client,PG: Request & Query Phase
    Client->>Ctrl: GET /store or POST /products
    Ctrl->>Svc: Action call
    Svc->>PS: prisma.product.create() / $transaction()
    PS->>PG: Parameterized SQL Query
    PG-->>PS: DB Row Results / JSONB
    PS-->>Svc: Typed Prisma Entities
    Svc-->>Ctrl: Processed Response
    Ctrl-->>Client: HTTP 200 / 201 Response

    Note over PS,PG: Shutdown Phase (onModuleDestroy)
    PS->>PG: $disconnect()
    PG-->>PS: Pool connections released

4. Query & Mutation Patterns in the App

Pattern Prisma API Call Service File Behavior & Safeguards
Point Lookup prisma.product.findUnique({ where: { id } }) products.service.ts Single index scan by primary key; throws 404 NotFoundException if not present.
Catalog Listing prisma.product.findMany({ orderBy: { createdAt: 'desc' } }) products.service.ts Returns all catalog items sorted newest first.
FK Integrity Guard prisma.category.findUnique({ where: { name } }) products.service.ts Validates category exists prior to product insertion/patching to avoid relational constraint failure.
ACID Transaction prisma.$transaction(async (tx) => { ... }) store.service.ts Upserts categories, upserts products, and deletes pruned items in an atomic database transaction.
State Document Upsert prisma.appStore.upsert({ where: { id: 1 }, ... }) store.service.ts Saves non-relational client state (cart, wishlist, orders) inside row id: 1 as JSONB.
Catalog Auto-Migration productCount === 0 && categoryCount === 0 store.service.ts Detects first run with relational schema and imports products from stored JSON to PostgreSQL tables.

5. Key File References

schema.prisma backend/prisma/schema.prisma

Declares AppStore, Category, and Product models with indexes and relations.

prisma.service.ts backend/src/prisma/prisma.service.ts

Binds Prisma to NestJS lifecycle via OnModuleInit ($connect) and OnModuleDestroy ($disconnect).

store.service.ts backend/src/store.service.ts

Implements hybrid catalog synchronization and atomic transactions with prisma.$transaction.

products.service.ts backend/src/products.service.ts

Handles CRUD operations, input sanitization, UUID generation, and category foreign key enforcement.
