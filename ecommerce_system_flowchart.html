🔒 Mutual Role Exclusivity

Login auto-detects roles. Customers cannot mutate admin routes, and admins cannot contaminate customer carts.

⚡ 1-Page = 1-API Rule

Global mount loops eliminated. Individual page components query only their necessary slice.

🛡️ Fetch Interceptor

backend.js injects 1-hour JWT tokens and intercepts 401 Unauthorized responses to trigger auto-logout.

⚡ Prisma ACID Transaction

Uses prisma.$transaction ensuring that stock decrements and order creation either all succeed or all roll back.

🛡️ Oversell Prevention

If an item has 0 stock, the transaction aborts with a 400 Bad Request before taking customer payment.

🧹 Automatic Cart Cleared

Upon transaction completion, the backend purges the customer's cart and Redux dispatches clearCart().

📦 Relational Products & Categories

Product has a foreign key to Category.name with onUpdate: Cascade, onDelete: Restrict.

🗄️ Dual-Storage Architecture

Catalog items are relational for high-performance indexing, while session data is persisted in app_store JSONB.

🔍 Performance Indexing

Indexed on products(name) and products(category) for sub-millisecond filtering.
